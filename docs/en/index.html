Speak, and it’s written.

An open-source menu bar voice input app for macOS. No account, no server — audio goes straight from your Mac to OpenAI, everything else stays on your machine.

Download for macOS Documentation

macOS 14+ · Free for non-commercial use · Bring your own OpenAI API Key

Fn start recording → speak → Fn stop → text appears at the cursor

Designed for everyday input

It feels like a system capability rather than an app: no window to open — just press Fn.

Global voice input

Press Fn in any app and speak; polished text is inserted right at your cursor without stealing focus or interrupting you.

Translate as you speak

Hold Fn + Left Shift, speak Chinese, get English. Switch the target language right on the floating bar.

Command selected text

Select some text and say “translate to Chinese”, “make it shorter”, or “turn this into a list” — replaced in place.

Personal glossary

Names, project names, and commonly misheard words get recognized with your preferred spelling. Stored locally only.

Context aware

Reads a small amount of text near your cursor to help with proper nouns and punctuation; degrades silently when unavailable.

Transcription history

Every entry is one click away from being copied; Debug mode shows exactly what each request sent.

Privacy

OpenVoice has no central server and no account system. Apart from the audio and a small amount of text context sent when calling the OpenAI API, everything else — your API key, glossary, settings, and history — stays on this Mac. Context features can be turned off under Settings → Privacy.
