话音落处，文字已成

一款开源的 macOS 菜单栏语音输入法。无账号、无服务器—— 音频直接从你的 Mac 发给 OpenAI，其余一切只保存在本机。

macOS 14+ · 免费（非商业用途）· 使用自己的 OpenAI API Key

Fn 开始录音 → 说话 → Fn 停止 → 文字出现在光标处

为日常输入而设计

它更像一种系统能力：不必打开主窗口，按一下 Fn 就够了。

🎙️

全局语音输入

在任何 App 里按 Fn 说话，整理好的文字直接插入光标位置，不抢焦点、不打断你。

🌍

边说边翻译

Fn + 左 Shift 说中文，出英文。悬浮条上可临时切换目标语言。

✨

对选中文字下指令

选中一段文字，说「翻译成中文」「写短一点」「整理成列表」，结果直接替换。

📖

个人术语表

人名、项目名、常被听错的词，识别会优先用你的拼写。全部只存本机。

🧠

上下文感知

读取光标附近的少量文字帮助识别专有名词与断句；读不到时自动降级，绝不报错。

⏳

转录历史

每条转录都可一键复制；Debug 模式下还能查看每次请求实际发送了什么。

隐私声明

隐私原则只有一条：每次只把当前语音请求所需的音频和少量文本上下文发送给 OpenAI，其余内容全部留在本机。

  • ✓你的 API Key 只保存在 macOS 钥匙串——不进日志、不进配置文件、不上传到任何第三方服务器。
  • ✓音频只发往 OpenAI 官方 API——OpenVoice 本身没有服务器，也没有账号系统，看不到你的任何数据。
  • ✓术语表、设置、历史全部存本机——没有云同步，没有遥测分析。
  • ✓上下文读取只用 Accessibility API——不截图、不 OCR、不申请屏幕录制权限、不做键盘记录。
  • ✓一切可关闭——上下文相关功能可在 设置 → 隐私 中逐项关掉；关掉后语音输入照常工作。
