「言出法随」

一款开源的 macOS 菜单栏语音输入法。无账号、无服务器—— 音频直接从你的 Mac 发给 OpenAI，其余一切只保存在本机。

macOS 14+ · 免费（非商业用途）· 使用自己的 OpenAI API Key

Fn 开始录音 → 说话 → Fn 停止 → 文字出现在光标处

为日常输入而设计

全局语音输入

在任何 App 里按 Fn 说话，整理好的文字直接插入光标位置，不抢焦点、不打断你。

边说边翻译

Fn + 左 Shift 说中文，出英文。悬浮条上可临时切换目标语言。

对选中文字下指令

选中一段文字，说「翻译成中文」「写短一点」「整理成列表」，结果直接替换。

个人术语表

人名、项目名、常被听错的词，识别会优先用你的拼写。全部只存本机。

上下文感知

读取光标附近的少量文字帮助识别专有名词与断句；读不到时自动降级，绝不报错。

转录历史

每条转录都可一键复制；Debug 模式下还能查看每次请求实际发送了什么。

隐私声明

OpenVoice 没有中央服务器，也没有账号系统。除了调用 OpenAI API 时发送的当次录音和少量文字上下文， 其余信息——API Key、术语表、设置、历史记录——都只保存在这台 Mac 上。 上下文相关的功能可以在 设置 → 隐私 中关闭。
